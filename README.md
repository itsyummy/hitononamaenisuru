# 人の名前にする

ランダムに出てくるひらがなを好きな位置に置いて、人の名前っぽくする遊びです。

https://itsyummy.github.io/hitononamaenisuru/

## 遊び方

1. 名前の文字数（ランダム / 5〜8）と、濁点・半濁点・小文字への変換（使えない / 一度だけ使える / 常に使える）を選んで「はじめる」。
2. ひらがなが1文字ずつ出てくるので、置きたい枠をタップする。
3. 全部埋まったら完成。「もう一度」で同じ設定のまま再挑戦できます。

HTML / CSS / JavaScript だけで動くので、`index.html` をブラウザで開くだけでも遊べます。
